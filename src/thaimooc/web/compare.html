01 / SAME INPUT

เปรียบเทียบบนข้อมูลเดียวกัน

ทั้งสองวิธีอ่านชื่อ คำอธิบาย และผลลัพธ์การเรียนรู้ชุดเดียวกัน ตรวจ fingerprint ของข้อมูลทุกครั้ง

02 / DIFFERENT REPRESENTATION

ต่างที่วิธีแทนข้อความ

TF-IDF ใช้ character n-grams ส่วน E5 ใช้ embeddings เอกสารยาวแบ่งเป็นช่วงข้อความแล้วเลือกคะแนนช่วงที่สูงที่สุดต่อวิชา
